两条口径先记住，后面全都靠它们：

1. 权重是两层相乘：一行分数的权重 = 该列「列权重」× 该「考核类型」的「缺省权重」。

2. 只有勾了「计入总评 = 是」的考核类型，才会进入期末结转。这是控制「哪些分算进期末」的总开关。

2. 路径一：平时练习打分

入口：教学管理 → 成绩册 /markbook

1. 选班级：顶部选「班级」。⚠️ 名单实际按学生档案的当前年级分组（系统里「当前班级」字段目前是空的），所以这里选的是年级（Pre-1 / Pre-2 / Pre-3 / 大一 / 未来企业家班 / 全球领航计划）。

2. 新建考核列（一列 = 一次考核）：填

列名称（如「9/18 课后练习」）· 考核类型（选 日常练习）· 科目（从已有值下拉选，期末总评按它拆科目）·

列权重 · 满分 · 等级体系 · 考核日期 · 排序 · 状态 ·

学生可见 / 家长可见（三态：未设置 / 是 / 否，只有选「是」才公开）·

完成日期（家长可见闸门，留空 = 不设闸门，到该日期前家长看不到这一列）。

「关联作业」在列编辑里只做展示，绑定入口在网格下方的作业同步面板。

3. 录分：点格子直接输入 → 右上角 「保存 N 处改动」（一次提交整块网格，可以录完一屏再保存）。

4. 看结果：网格右侧三列是实时算出来的 —— 总评（按两层权重加权）、等级、目标。

5. 改过等级体系 / 目标后，点 「重算快照」，否则历史条目的等级/达标还是旧值。

录入规则（重要）

单元格接受这些写法（2026-09-20 起）：

- 85 —— 按该列满分制的原始分

- 85% —— 按该列满分折算（满分为 50 时，85% = 42.5）

- 字母等级（如 B）—— 按该等级体系的分数区间取中位折算

- * 或 免考 —— 免考（得分为空；默认不进总评分母）

- 缺 —— 缺考（按 0 分；默认计入分母）

- 留空 —— 未录入（保存后会删掉这一格）

免考与缺考在格子里显示成「免考 / 缺考」，不会显示成空白或 0 —— 这两者对总评分母的影响完全不同，混起来看会让总评变得没法解释。

输入了服务端不认识的写法（如等级体系里没有的字母 Z）会报错且不落库，不会静默丢。

作业联动：网格下方 「作业同步」面板（有未保存改动时面板不显示）—— 选一份作业 → 预览 → 同步，系统把「已完成」的学生按满分（或提交得分）写进对应列；未完成留空，不会写 0。

建议做法：日常练习的考核类型设成 日常练习（计入总评=否）。这样这些列只是过程留痕，不会进入期末结转，期末那一步才不会被几十列练习分搅乱。

3. 路径二：月考的准备与评估

准备（30 分钟）

1. 批次：为这次月考建一个成绩批次（或直接用覆盖全学期的批次）。起止日期建议覆盖到考试当天。

2. 列：在成绩册里给每个科目新建一列，考核类型选 月考，考核日期 填考试日期（必须落在批次区间内，否则不参与结转）。

3. 录分：同第 2 节；考完集中录入 + 保存。

评估（四步，都在 /exam-grades 的「期末总评」Tab）

1. 预览结转：选 批次 + 班级 + 科目 → 点「预览结转」，先看条数与分数是否合理，确认无误再 「一键结转」。系统按 Σ(百分制得分 × 权重) ÷ Σ权重 算出每位学生的总评（分母只算参与项）。

2. 异常成绩审查：5 条规则自动提示 —— 超满分 / 零分 / 离群偏高 / 离群偏低 / 突变。只提示、不改分，用来复核录入错误。离群阈值可在「成绩口径」里调（倍数与突变分差）。

3. 看分布与排名：报表里「考试成绩分布」「GPA 与班级排名」（排名需要先给等级配绩点，范围 = 同批次 + 同科目 + 同班级）。

4. 确认：逐条「确认」或「全部确认」。确认后不能改分（要改先「撤销确认」）。

出材料

批量评语 Tab：按科目挑常用评语一键套用，失焦即存；已确认的评语会锁定。

成绩单 Tab：写班主任总评语 → 单份 导出 PDF 或 整班导出 ZIP（导出次数会记在成绩单上，便于追踪）。

4. 路径三：学期末成绩（平时 + 月度 + 期末 + 实践）

⚠️ 先说清机制：系统的期末总评只从成绩册这一个来源按科目加权算出来，没有「四类来源权重」这种配置项。
但用「考核类型 × 列权重」完全可以精确表达你要的占比，做法就是把四类各汇成一列。

四步做法

第 1 步：类型准备（第 1 节已建好）

类别考核类型计入总评成绩册里建几列该类的列权重
日常练习（过程留痕）日常练习否每次练习一列随意（不进合成）
平时成绩平时成绩是每科 1 列40
月考月考是每次月考 1 列（等权）20 ÷ 月考次数（如 2 次 → 各 10）
期末考试期末考试是每科 1 列30
实践课程实践课程是每科 1 列10

第 2 步：填「汇总列」的分数

平时成绩：填平时练习的加权平均 —— 直接抄网格右侧算好的 总评（或按你的口径手算）。不要把几十列练习都设成「计入总评」，那会让占比失控。

月考：每次考完就填那一列（一学期 3 次就 3 列、各 20/3）。

期末考试：考试成绩照实填。

实践课程：按实践表现评定一个 0–100 的分填进去（系统里「实践活动」模块没有分数字段，实践分由老师给定，这里作为它的落地位置）。

第 3 步：结转

批次起止日期覆盖整个学期 → /exam-grades 选批次/班级/科目 → 预览 → 一键结转。

算出来的就是：

```

期末总评 = (平时×40 + 月考×20 + 期末×30 + 实践×10) ÷ 100

```

（权重和是自归一化的：分母只累加"实际参与"的项，所以改了占比不用动别的地方。）

第 4 步：确认与出成绩单

逐条确认 / 全部确认 → 写班主任总评语 → 导出 PDF 或整班 ZIP。

三条必须知道的注意

1. 占比只调「列权重」，别再动类型缺省权重——两层是相乘的，同时改很容易算错（类型权重保持 1 最省心）。

2. 缺考 / 免考 / 未录入会让分母变小，占比会自动重分配（这就是"不计入分母"的语义）。如果你要的是「缺考按 0 分算、不要重分配」，把批次的 缺考处理 设成 计0分（默认值就是它）；免考处理 默认 不计入分母。

3. 期末总评是快照：成绩册改分后不会自动更新，要重新「一键结转」；已确认的记录不会被覆盖，改分前先「撤销确认」。

6. 目前做不到（照实说，别指望）

1. 期末总评不能自动合成四类来源 —— 它只按成绩册加权。第 4 节那套「汇成四列」是目前唯一可行且准确的替代做法。

2. 没有「月考」这个实体 —— 用「一个叫『月考』的考核类型 + 科目 + 成绩批次」来表达，批次名靠人工约定。

3. 期末总评与成绩单没有独立列表页：结转结果与分析都在「考试与成绩」页里看，逐条改评语也从那里进。

4. 成绩册不支持粘贴 Excel / 整列填充 / 导入导出：只有整块保存、作业同步、重算快照。

5. 「输入已被修正」的提示未逐条展示：服务端会返回修正明细（如超满分截断、负数归 0），页面目前只提示保存条数。

6. 家长 / 学生门户看不到期末总评与成绩单 —— 门户只读成绩册的条目（按可见性过滤）+ 作业 + 家校沟通。

7. 出勤率不进任何成绩；「实践活动」「学习成果」两个模块没有成绩字段，不参与合成（实践课分只能像第 4 节那样手工落到成绩册列里）。

8. 教学班维度不可用（教学班表为空）：类型权重表若要按「教学班」配是匹配不上的，实际按班级文本匹配 —— 只填教学班不填班级会静默不生效。

7. 常见问题

Q：改了成绩，期末总评怎么没变？

A：总评是结转时写下的快照。重新「一键结转」即可；已确认的记录要先「撤销确认」。

Q：某次成绩没进期末总评？

A：按顺序查三件事 —— ① 该列的 考核日期 是否在批次起止区间内；② 该列 状态 是否被停了；③ 该列的 考核类型 是否勾了「计入总评」。另外，考核类型要与类型表的写法逐字一致（成绩册里是手打的，写错一个空格/同义词就匹配不上，而且不报错）。

Q：家长看不到成绩？

A：成绩册列的 学生可见 / 家长可见 必须显式为「是」（空值 = 不可见），且家长端还多一道 完成日期 闸门（空 = 不设闸门）。这三个开关现在都能在成绩册 → 列上的「编辑」里直接设。

Q：为什么权重没生效？

A：检查类型权重表填的是不是 「班级」（不是「教学班」）；以及成绩册列上的类型文字是否与类型表一致。
